# Microsoft Exchange Online Administration and Support

A hands-on learning portfolio focused on Microsoft Exchange Online administration, mailbox management, mail flow, and day-to-day Exchange Online administrative tasks. This project documents my learning journey through practical labs, configurations, and real-world Exchange Online administration scenarios.

## Live Website

## Overview

This portfolio is designed to strengthen practical Microsoft Exchange Online administration skills commonly required for IT Support, Help Desk, Service Desk, Microsoft 365 Support, and Exchange Online Administrator roles.

The project covers the Exchange Admin Center and demonstrates common administrative tasks performed in enterprise Microsoft 365 environments.
